# Conception d’un Réseau IP Multi-Sites

Ce projet consistait à concevoir et configurer un réseau IP reliant trois sites (Montréal, Saint-Hubert et Brossard) à l’aide de protocoles de routage dynamique (RIP, OSPF et EIGRP).  
L’objectif principal était de centraliser le service DHCP et d’assurer la communication complète entre les trois sites via des liaisons WAN.  

J’ai réalisé :
- Le plan d’adressage IP et la configuration complète des routeurs Cisco  
- Les tests de connectivité et la validation du routage  
- La sauvegarde et la persistance des configurations
