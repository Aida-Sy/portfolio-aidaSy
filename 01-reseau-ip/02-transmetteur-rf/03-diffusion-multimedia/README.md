# Diffusion Multimédia — Distribution des Signaux Vidéo

Ce laboratoire visait à concevoir une chaîne complète de diffusion multimédia composée de modulateurs, d’un assembleur, d’un amplificateur et d’un PMD pour la distribution de signaux vidéo sur plusieurs canaux TV.  

J’ai effectué :
- Le câblage et la configuration des modulateurs sur des fréquences VHF/UHF  
- Le calcul du PMD pour équilibrer les niveaux des signaux  
- Les mesures à l’aide d’un analyseur de spectre pour vérifier la qualité du signal
